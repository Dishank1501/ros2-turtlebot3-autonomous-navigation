# Assignment Report: TurtleBot3 Autonomous Navigation

## 1. Objective

To set up and test a TurtleBot3 Burger simulation using ROS 2 Humble, Gazebo Classic, and Navigation2 (Nav2), and visualize the navigation system in RViz.

## 2. Technologies Used

- Ubuntu 22.04
- ROS 2 Humble
- TurtleBot3 Burger
- Gazebo Classic
- Navigation2 (Nav2)
- RViz
- AMCL
- TF2

## 3. Approach

1. Launched the TurtleBot3 Burger simulation in Gazebo Classic.
2. Started the Navigation2 stack with simulation time enabled.
3. Used RViz to visualize the robot, map, laser scans, and navigation costmaps.
4. Initialized the robot's estimated pose using the 2D Pose Estimate tool.
5. Investigated navigation behavior and ROS 2 transforms during testing.

## 4. Challenges

The main troubleshooting areas included localization initialization, TF transform availability, Nav2 lifecycle states, and robot movement behavior.

ROS 2 topic inspection, lifecycle checks, TF2 tools, and RViz visualization were used to investigate these issues.

## 5. Results

The Gazebo simulation and RViz navigation visualization were used to inspect the robot and its navigation system.

Refer to the project screenshots and demonstration video for visual evidence of the tested setup.

## 6. Learning Outcomes

- Learned how to launch a TurtleBot3 simulation using ROS 2.
- Explored the integration of Gazebo, Nav2, AMCL, and TF2.
- Practiced troubleshooting ROS 2 nodes, topics, transforms, and lifecycle states.
- Gained experience visualizing robot navigation in RViz.
